# AI Rules & Guidelines for Bedifly (Grow 10x Digital)

## Tech Stack Overview

- **Framework**: React 19 with TanStack Start for SSR and static pre-rendering.
- **Routing**: TanStack Router using file-based routing inside `src/routes/` (`__root.tsx` as root layout, `index.tsx` for main page).
- **Language**: TypeScript (`.tsx` and `.ts` files with strict type checking).
- **Styling**: Tailwind CSS v4 using `@tailwindcss/vite` and custom theme CSS variables defined in `src/styles.css`.
- **UI Component Primitives**: Radix UI primitives with shadcn/ui architecture located in `src/components/ui/`.
- **Icons**: Lucide React (`lucide-react`).
- **Data Fetching & State**: TanStack Query (`@tanstack/react-query`).
- **Form Management & Validation**: React Hook Form (`react-hook-form`) combined with Zod (`zod`) schemas via `@hookform/resolvers`.
- **Toasts & Notifications**: Sonner (`sonner`).
- **Build & Dev Tooling**: Vite 8 with `@lovable.dev/vite-tanstack-config`.

---

## Library Usage & Coding Rules

1. **Routing & File Organization**
   - Place all application routes inside `src/routes/`.
   - Never create `src/pages/` or Next.js/Remix style layout directories.
   - Do NOT edit `src/routeTree.gen.ts` directly; it is auto-generated by TanStack Router.

2. **UI & Components**
   - Always use existing shadcn/ui components located in `src/components/ui/` or Radix UI primitives.
   - Do NOT modify `src/components/ui/` files directly unless instructed—create custom components in `src/components/` instead.
   - Use Lucide React (`lucide-react`) for all UI icons.

3. **Styling Standards**
   - Use Tailwind CSS classes for layout, typography, and responsive designs.
   - Use custom theme utility classes (`bg-hero`, `glass`, `shadow-glow`, `shadow-navy`, `text-gradient-orange`, etc.) configured in `src/styles.css`.
   - Maintain color consistency: Navy Blue (`--navy`, `--navy-deep`) and Orange (`--orange`) brand accents.

4. **Forms & Inputs**
   - Use `react-hook-form` along with `zod` for form validation and input state handling.
   - Use `sonner` for toast notifications when displaying user feedback or form submission status.

5. **API & Data Handling**
   - Client-side data fetching and caching should utilize TanStack Query (`@tanstack/react-query`).
   - Server functions should use TanStack Start `createServerFn`.
   - Webhook submissions (e.g. Google Sheets lead capturing) reside in `src/lib/leads-webhook.ts`.
